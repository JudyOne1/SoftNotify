# 阶段 8 调研与改造方案（弹幕交互增强 × 习惯游戏化 × 番茄钟）

_2026-08-29 起草。覆盖 ideas.md 第十二节（高频微功能）与第十五节（番茄钟）。竞品依据见 ideas.md 第三轮调研（Stretchly/Waterllama/sobreak/SafeEyes）。_

## 0. 现状基础（都已就绪）

- 悬停打卡交互（穿透轮询 + 按钮）——贪睡/strict 的 UI 载体
- stats.json 打卡记录 + 每日聚合——streak/成就的数据源
- anchorAt 锚点机制——贪睡的实现载体
- 全屏/会议免打扰——番茄钟专注期的静默联动

## 1. 贪睡 Snooze

**交互**：弹幕悬停按钮变为三个：「✓ 完成了」「+5 分钟」「忽略」。
- 点「+5 分钟」→ 当前弹幕消失，5 分钟后同一条提醒再次飘出（文案重抽）
- 贪睡不记打卡；触发时**遵守**安静时段/全屏/会议静默（开会时贪睡的提醒不吵）

**实现**：`main/snooze.ts` 运行时列表 `{ itemId, timer }`（不持久化——贪睡是短时行为，应用重启即失效，符合直觉）；触发走 `remind(entry, false)`。多次贪睡同一项：重置 timer 即可。

## 2. 逐级升级提醒（sobreak 模式）

- 每个提醒项内存计数 `snoozeCount`（当日有效，打卡后清零；重启清零可接受）
- **第 2 次贪睡起升级**：弹幕字号 ×1.2、速度放慢，文案从「升级池」抽取（如「说好的喝水呢？」「上次说 5 分钟，已经过去 15 分钟啦」），升级池与该项自定义文案合并随机
- 不加设置开关：第 2 次才触发，足够克制
- **成本：低**（snooze.ts 计数 + remind 传 escalation 级别 → OverlayApp 应用样式 + 文案池）

## 3. Strict 模式（不可忽略）

- 提醒项加 `strict?: boolean`（「更多」里开关，默认关）：strict 弹幕**不显示忽略按钮**（只能完成或贪睡）
- 与重要度正交（普通也可 strict）
- **成本：低**

## 4. Streak 连续天数

**口径（待所有者确认）**：按「每项每日目标」分别计算——某项当天打卡数 ≥ dailyGoal 记为达标；该项 streak = 截止今天（或昨天）的连续达标天数。无目标项不参与 streak。
- 统计页每张目标卡右上角显示 🔥N；总览行显示「全勤 streak」（所有目标项都达标的天数）
- 今天还没达标不算断（看到昨天为止），今天达标则含今天
- **实现**：纯函数 `computeStreak(dailyCounts, goal, today)` 放 shared（可单测），stats.ts 聚合时调用
- **成本：中低**

## 5. 成就 / 里程碑庆祝

- Streak 里程碑 3/7/14/30 天达成时：当天首次触发该提醒 → 特殊庆祝弹幕（「🔥 连续 7 天达标！」）+ 写入历史
- 已庆祝里程碑存 stats.json `celebrated: string[]`（如 `water-7`）防重复
- 挑战系统（自选挑战/徽章墙）**延后**——先做里程碑庆祝验证反馈
- **成本：低**

## 6. 番茄钟专项

**v1 形态（托盘驱动，手动开始）**：
- 托盘「🍅 专注」子菜单：25 / 45 / 60 分钟 + 「停止专注」
- 会话状态机：`idle → focus(endsAt) → break(5min) → idle`
- focus 开始：其余提醒**静默**（用户要求的核心：专注时不被打扰；🍅 结束提醒本身豁免）
- focus 结束：特殊弹幕「🍅 专注 N 分钟完成！休息 5 分钟，起来走走」（豁免一切静默，視同 manual）
- break 结束：弹幕「休息结束，继续加油」→ 会话结束（v1 不自动循环）
- 托盘 tooltip：「专注中 · 剩余 N 分钟」；每分钟刷新（复用 refreshTray 定时器）
- 统计：stats.json `focusSessions: Record<date, number>`，统计页今日卡片「🍅 专注 N 次」
- 中途停止（托盘「停止专注」）：不满 5 分钟不计次；≥5 分钟计半次？——v1 从简：手动停止不计次（完成才算）

**实现**：`main/pomodoro.ts`（状态机 + 超时回调 + isPomodoroActive() 供 remind 静默判断）；stats 加计数；托盘子菜单。不用 schedule 引擎（会话是一次性运行态，setTimeout 足够）。
**成本：中**
