# Notify 功能想法池（头脑风暴）

_2026-08-29 整理。这是想法池不是承诺，勾选仅表示方向被认可，进入开发前需在 development-plan.md 立项。_

**筛选原则**：Notify 的灵魂是「弱提醒、不打断焦点」。好功能应该让弹幕**更懂时机**或**更有用**，而不是变成弹窗怪物。每个想法按此原则取舍。

当前基础：阶段 1-3 已完成（多提醒计划、自定义文案/音频、安静时段、主题速度、CI）。国际化进行中待做，版本 0.2.0。

## 一、提醒时机：补全「定时点」场景

现在的间隔提醒之外，很多真实需求是「到某个点」：

- [x] **每天定时提醒**（cron 式）：「每天 10:00 站会」「周三 17:00 写周报」「每天 23:00 该睡了」。与多提醒计划模型互补，是当前**缺口最大**的功能
- [x] **一次性倒计时**：「30 分钟后提醒我取快递」，托盘菜单/快捷键快速创建
- [ ] **番茄钟模式**：25+5 循环，休息时弹幕劝你起身。与产品气质契合，可作为提醒计划的一种预设类型
- [ ] **使用时长触发**：连续使用电脑 N 小时后强提醒休息（健康向，比固定间隔科学）

## 二、从「提醒」到「闭环」：打卡与统计

提醒飘过即逝，用户与提醒之间缺反馈：

- [ ] **可交互弹幕**：悬停/按住时临时取消穿透，点「知道了/已完成」记一笔。技术上需处理穿透窗口的交互切换
- [ ] **打卡统计**：今日喝水 6/8 杯、本周休息 23 次；托盘 tooltip 或设置页图表呈现
- [ ] **周报回顾**：上周提醒执行情况，弹幕形式回顾或导出

## 三、开发者生态：传播点

把 Notify 从「健康提醒工具」升级为「桌面弹幕通知的通用出口」：

- [ ] **Webhook / 本地 HTTP API**：外部事件推弹幕——CI 完成、服务器告警、邮件到达。`curl localhost:<port>/say 文案` 即飘屏。长期最有想象力，建议核心体验稳定后再做
- [ ] **命令行 CLI**：`notify "该提交代码了" --in 5m`
- [ ] **全局快捷键**：随时唤起自定义弹幕（可当「便利贴」用）

## 四、个性化与聪明程度

- [x] **按时段换文案**：清晨/深夜文案不同（纯本地规则，成本低）
- [ ] **AI 生成文案**：可选接入 LLM API，按提醒类型生成不重样文案。保持「可选、无账号」底线
- [ ] **避开心流**：键盘鼠标活跃度检测，高强度工作时延迟提醒。比全屏检测成本低、更聪明
- [x] **多配置 Profile**：「工作 / 游戏 / 学习」模式一键切换，不同提醒组合+间隔。实现成本低，托盘加一组单选项

## 五、视觉与趣味

- [x] **弹幕样式自定义**：字体、描边、透明度、emoji 贴纸
- [x] **节日/纪念日弹幕**：生日倒计时、节日飘屏
- [x] **弹幕历史面板**：快捷键唤起，查看刚才飘过的内容

## 六、发布与运营

- [x] **自动更新**（electron-updater + GitHub Releases）：留存硬伤，建议国际化之后紧接着做
- [x] **首次安装引导**：选几个预设计划一键开跑
- [x] **应用内 Star 入口**：喜欢就点个 Star

## 优先级建议（2026-08-29 观点）

1. **每天定时提醒**——补全场景刚需
2. **自动更新**——运营基建，越早越好
3. **Profile 模式**——低成本高感知
4. **番茄钟**——气质契合、易传播
5. Webhook/API——长期想象力最大，排在核心体验稳定之后

# 第二轮头脑风暴（2026-08-29 · 功能落地后看到的新大陆）

_前六节是功能蓝图；这一轮补充做完全部一期功能后发现的**真实痛点**与**零成本机会**。_

## 七、弹幕表现打磨（可用性痛点，性价比最高）

- [ ] **车道分配**：多条弹幕同时出现时会随机重叠。把屏幕纵向分成 5-6 条车道，新弹幕优先选空车道——真实痛点，纯 OverlayApp 前端逻辑
- [ ] **时长按文案长度自适应**：现在飘过时长只跟速度档有关，长文案飘太快读不完。duration 按 `基础时长 + 字数 × 系数` 计算
- [ ] **重要度分级**：普通/重要两档。重要弹幕更大、更慢、可带音效、可选择同时进 Windows 通知中心
- [ ] **任务栏/托盘避让**：弹幕纵向位置避开任务栏区域（检测屏幕工作区而非全屏）
- [ ] **暗色弹幕配色自动切换**：跟随系统深浅自动换弹幕配色（现在是手动主题）

## 八、系统感知触发（Electron 免费送的信号，零依赖彩蛋）

- [ ] **间隔抖动**：固定间隔会让提醒变得可预测而被无视；实际触发时刻加 ±15% 随机抖动，恢复「惊喜感」
- [ ] **电池触发**：`navigator.getBattery()` 零成本——拔掉电源提醒「用电池啦，记得省点用」、电量低于 20% 提醒充电
- [ ] **网络触发**：断网/恢复联网时弹幕通知（对常年挂 VPN 的人有用）
- [ ] **连续使用时长**：`powerMonitor.getSystemIdleTime()` 轮询统计活跃时间，满 2 小时强提醒休息（真正的健康科学）
- [ ] **自然语言建日程**：输入「每天下午3点提醒我喝水」解析成定时日程（先本地规则解析，后可接 AI）

## 九、语音与无障碍

- [ ] **TTS 语音播报**：重要提醒可选语音读出来（Windows 内置 SAPI 免费，离线可用）——不看屏幕场景刚需
- [ ] **高对比模式**：弹幕描边加强 + 纯白文字，弱视/强光环境友好
- [ ] **键盘完全可操作**：设置页焦点顺序与快捷键梳理

## 十、数据洞察（把「提醒了」变成「做到了」）

- [ ] **打卡统计**：弹幕悬停可点「完成了」记一笔（需临时取消穿透，技术方案已论证可行）
- [ ] **每日喝水计数**：完成 N/8 杯进度，托盘 tooltip 展示
- [ ] **用电脑时长日历**：基于第八节的活跃统计，按日/周视图回看
- [ ] **数据导出**：CSV/JSON 导出打卡与历史记录

## 十一、工程质量（功能多了之后的护城河）

- [ ] **调度器单元测试**：调度器已经是双源+差量+唤醒补发的复杂状态机，上 Vitest 补测试防止回归——**建议下一个功能前做**
- [ ] **config 自愈**：config.json 损坏时自动备份并重置（现在是静默回默认值，用户会莫名丢配置）
- [ ] **设置窗口双开同步**：两开时草稿互不同步的已知债
- [ ] **E2E 冒烟**：Playwright + Electron 跑「添加提醒→触发→弹幕出现」主链路

## 第二轮优先级建议

1. **弹幕车道分配 + 时长自适应**——真实痛点、纯前端、一天内可完成
2. **调度器测试 + config 自愈**——发版（v0.3.0）前把地基打牢
3. **间隔抖动**——一行代码级别的体验提升
4. **HTTP API + 全局快捷键**（原第三节）——生态入口
5. **打卡统计 + TTS**——差异化亮点
