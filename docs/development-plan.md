# Notify 开发计划

## 产品定义

- **一句话**：跨平台定时提醒工具，用"弹幕飘屏 + 轻音效"的弱提醒方式，不打断用户焦点。
- **平台**：Windows / macOS / Linux
- **技术栈**：Electron + TypeScript + React（设置界面）+ electron-vite + electron-builder
- **开源**：GitHub 公开仓库，MIT 协议

## 决策记录（2026-08-28）

| 决策项 | 结论 | 理由 |
|---|---|---|
| 跨平台框架 | Electron | 透明穿透窗口方案最成熟，AI 辅助开发效率最高 |
| 开发语言 | TypeScript | 类型安全，生态主流 |
| 设置界面 | React + Vite | 用户选择 |
| 弹幕文案 | 先内置固定模板，后续支持自定义 | 用户选择 |
| 开源协议 | MIT | GitHub 开源主流 |
| Linux 支持 | 是 | 顺手支持 |
| 多提醒数据模型（2026-08-28） | `Config.reminders: ReminderItem[]`，单一定时器按最近触发时间调度，差量更新 | 改单项不重置其他项计时；旧配置自动迁移为一条「喝水」提醒 |
| 托盘立即提醒（2026-08-28） | 子菜单按提醒项单独触发 | 多计划下单一入口语义不明 |
| 国际化（2026-08-28） | 移至下一轮 | 所有者决策：先完成核心功能 |
| 代码签名（2026-08-28） | 暂缓 | 所有者无证书；macOS 公证需开发者账号 |

## 阶段规划

### 阶段 1：MVP（当前）

- [x] 项目骨架（electron-vite + TS + React + electron-builder 三端打包）
- [x] 主进程：托盘常驻、提醒调度器（休眠唤醒补偿）、本地配置存储
- [x] 弹幕悬浮窗：每显示器一个透明置顶穿透窗口，CSS 动画，随机车道/字号/颜色/速度
- [x] 提示音：Web Audio 合成，音量可配，仅主屏发声
- [x] 设置界面：提醒间隔、声音开关、音量、开机自启、测试提醒
- [x] 托盘菜单：立即提醒 / 暂停恢复 / 打开设置 / 退出

### 阶段 2：体验完善

- [x] 安静时段（时间段免打扰，默认 22:00-08:00，支持跨午夜）
- [ ] 全屏应用检测：独占全屏时跳过提醒（暂缓：需原生模块探测前台窗口，复杂度高收益低；置顶弹幕在无边框全屏下本就可见）
- [x] 错过提醒策略可配置（补发 / 丢弃）
- [x] 弹幕皮肤：颜色主题（天空/糖果/素雅）、速度档位（慢/正常/快）
- [x] 托盘图标状态指示（运行中蓝色 / 暂停灰色）

### 阶段 3：自定义与发布

- [x] 自定义提醒计划：多个提醒项（喝水/护眼/拉伸），各自间隔与文案
- [x] 自定义文案（每个提醒项独立文案，留空回退内置模板）
- [ ] 自定义音频文件（选择本地音频替代合成提示音）
- [x] GitHub Actions CI：三端自动构建 + Release 发布（.github/workflows/release.yml，tag v* 触发）
- [ ] 代码签名（可选，暂缓：无证书，见下方已知限制）
- [ ] 国际化（中/英）

## 已知限制（不在近期计划）

- Windows 独占全屏游戏/视频会盖住悬浮层（系统机制）
- macOS 分发需自行签名公证，否则用户需手动放行
