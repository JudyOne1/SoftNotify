# Notify

跨平台定时提醒工具：到点后一段轻音效 + 弹幕式文字从屏幕飘过，提醒你喝水、护眼、活动一下——**不打断你的焦点**。

- 平台：Windows / macOS / Linux
- 技术栈：Electron + TypeScript + React + Tailwind

## 特性

### 弹幕弱提醒
- 透明置顶穿透窗口，文字飘过即消失，不抢焦点、不弹窗、不进任务栏
- 多显示器支持，按屏幕纵向分道避免重叠
- 显示区域可调（全屏 / 上半屏 / 顶部 30% / 自定义拖拽）
- 不透明度 / 字号 / 描边自定义；飘过时长按文案长度自适应
- 输出屏幕可选（全部 / 仅主屏 / 指定显示器）

### 提醒计划
- **间隔提醒**：天 / 时 / 分 / 秒滚轮精调（5 秒 ~ 7 天）
- **定时日程**：每天 / 每周几 / 单次倒计时，到点自动停用
- **起始锚点**：设定下次提醒时间，此后按间隔顺延，重启保持相位
- **间隔抖动**：可选随机偏移，让提醒不那么可预测
- 每个提醒项独立配置：重要度、严格模式、每日目标、提示音色、夜间文案、忽略安静时段

### 打卡与统计
- 悬停弹幕即可打卡（弹幕自动暂停），托盘可补打卡
- GitHub 式活跃热力图（打卡次数 / 活跃时长可切换）
- Streak 连续天数 + 里程碑庆祝弹幕（3/7/14/30/50/100 天）
- 数据本地保存，支持 JSON 导出

### 声音
- 5 种离线合成音色（经典双音 / 风铃 / 水滴 / 木鱼 / 八音盒）
- 支持自定义音频文件（mp3/wav/ogg/m4a/flac）
- 全局默认 + 提醒项单独覆盖

### 免打扰
- 安静时段（支持跨午夜）
- 会议模式：托盘手动开关 + 摄像头/麦克风占用自动检测（Windows）
- 全屏免打扰：观影 / 游戏时自动静默
- 番茄钟：专注期间自动静默其他提醒

### 番茄钟
- 托盘 / 设置页一键开始（25/45/60 分钟）
- 专注结束弹幕提醒休息，休息结束提醒继续
- 自动循环可选，完成次数计入统计

### 其他
- **模式**：提醒项组合一键切换（工作 / 下班 / 游戏…），托盘直达
- **弹幕历史**：最近 50 条，随时回看
- **节日祝福**：公历 + 农历节日当天首次提醒自动附祝福语
- **自动更新**：GitHub Releases，下载完成后退出即装（macOS 无签名时降级为手动下载）
- 开机自启、休眠唤醒补发/丢弃策略

## 开发

```bash
npm install
npm run dev        # 启动开发模式（带 HMR）
npm run typecheck  # 类型检查
npm test           # 单元测试（调度/模式/Streak 核心）
npm run build      # 构建（输出到 out/）
```

## 打包与发布

```bash
npm run build:win    # NSIS 安装包
npm run build:mac    # DMG
npm run build:linux  # AppImage + deb
```

推送 `v*` tag 会触发 GitHub Actions 三平台自动构建，并上传安装包与自动更新元数据到 Draft Release（人工确认后发布）。
